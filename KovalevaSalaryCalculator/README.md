# KovalevaSalaryCalculator (v9.2 FINAL)

Профессиональное консольное приложение для расчета заработной платы сотрудников ИП Ковалева Т.С.

## Основные возможности
- **Законодательство 2025:** Полная поддержка прогрессивной шкалы НДФЛ (13%, 15%, 18%, 20%, 22%).
- **Детские вычеты:** Новые ставки 2025 года (2800 руб. на 1-2 ребенка, 6000 руб. на 3+).
- **Льготы МСП:** Расчет страховых взносов по ставке 15% для сумм превышающих 1 МРОТ.
- **Цикл выплат:** Поддержка аванса и итогового расчета с автоматическим вычитанием удержаний.
- **Snapshot-архитектура:** Все расчеты сохраняются со снимком настроек (МРОТ, оклад) на момент расчета.
- **Экспорт:** Генерация текстовых расчетных листков и сводных ведомостей.

## Структура проекта
- `Program.cs`: Интерфейс и управление потоком данных.
- `Models/`: Описание сущностей и настроек.
- `Services/`: Бизнес-логика (SalaryService) и хранение (StorageService).
- `Tests/`: Набор автоматизированных проверочных тестов.
- `Data/`: Автоматически создаваемая папка для хранения JSON-файлов.

## Использование
Запуск приложения:
```bash
dotnet run
```

Запуск проверочных тестов:
```bash
dotnet run -- --test
```

Полный сброс данных:
```bash
dotnet run -- --reset
```

## Требования
- .NET 8.0 SDK или выше.
